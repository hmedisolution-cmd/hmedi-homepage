# 진료과 페이지 초안 (아직 공개 전)

대표 승인 후 적용한다.

1. `marketing-*.html` 세 파일을 `build/src/` 로 옮긴다
2. `pages.json` 의 세 항목을 `build/build.py` 의 `PAGES` 에 넣는다 (제목 · 설명 · 키워드 · H1 · 경로 이름 · 서비스명 순)
3. `build/src/marketing.html` 에 진료과별 마케팅 링크 묶음을 넣는다

## 의료법 대응 구역 (아직 공개 전)

1. `compliance-section.html` 을 `build/src/marketing.html` 의 FAQ 섹션 바로 위에 넣는다
2. `compliance-faq.html` 의 질문 하나를 같은 페이지 FAQ 목록 맨 위에 넣는다
